# 모임픽 (moim-pick)

여러 사람이 모일 날짜를 정하는 작은 웹앱입니다. 링크를 보내면 각자 안 되는 날에 줄을 긋고, 모두 되는 날을 바로 보여 줍니다.

- 첫 화면에서 모임 이름을 검색해 들어가거나, 없으면 새로 만듭니다. 만들 때 '이름으로 검색 허용'을 끄면 링크를 받은 사람만 들어올 수 있습니다.
- 모임을 만들면 공유용 링크(`/e/모임ID`)가 생깁니다.
- 참여자는 로그인 없이 이름, 관계, 출발역(선택)을 적고 안 되는 날을 표시합니다. 응답은 응답한 기기에서만 고칠 수 있고, 주최자는 누구의 응답이든 고치거나 지울 수 있습니다.
- 주최자는 결과에서 날짜와 역을 확정하고 공지 문구를 복사할 수 있습니다.
- 결과 탭에서 모두 되는 날, 빠지는 사람이 적은 날 순위, 날짜별 불가 인원을 볼 수 있습니다.
- 모임과 응답은 마지막 수정 후 120일이 지나면 자동으로 지워집니다.

## 시간대와 모임장 일정

- 모임을 만들 때 시간대를 고릅니다: 점심만, 저녁만, 점심·저녁 둘 다. 둘 다 받는 모임은 달력의 원을 위아래로 나눠 위쪽은 점심, 아래쪽은 저녁으로 표시합니다. 날짜를 누르면 하루 전체가 바뀌고, 아래에 뜨는 버튼으로 점심·저녁만 따로 고칩니다.
- **모임장**은 여러 모임을 만든 한 사람입니다. 처음 모임을 만들 때 브라우저에 모임장 열쇠(토큰)가 저장되고, 그 뒤에 만든 모임은 모두 같은 모임장에 묶입니다. 로그인은 없습니다.
- `/host`(모임장 일정)에서 내가 안 되는 시간을 눌러 두면, 내가 만든 모든 모임에서 그 칸은 아무도 고를 수 없습니다.
- 한 모임을 확정하면 그날(점심·저녁 모두)은 내 다른 모임에서 고를 수 없게 됩니다. 그 모임에 이미 응답한 사람에게는 다음에 열 때 "후보에서 빠진 때가 있어요" 안내가 뜹니다. 푸시 알림은 없습니다.
- 다른 기기에서도 모임장으로 쓰려면 `/host`의 **모임장 링크 복사**로 받은 주소를 그 기기에서 엽니다. 이 링크를 가진 사람은 내 모든 모임을 관리할 수 있습니다.

## 관리 (모임·응답 삭제)

- 모임을 만든 기기에서는 결과 화면 아래에 **모임 관리**가 보입니다. 여기서 응답을 하나씩 지우거나 모임 전체를 지울 수 있습니다.
- 다른 기기에서 관리하려면 **관리 링크 복사**로 받은 주소(`/e/모임ID#admin=토큰`)로 한 번 열면 됩니다. 이 링크를 가진 사람은 누구나 모임을 지울 수 있으니 공유하지 마세요.
- 관리 토큰은 서버에 해시로만 저장됩니다. 토큰을 잃어버렸거나 이 기능이 생기기 전에 만든 모임은 Upstash 콘솔의 Data Browser에서 `mp:event:모임ID`, `mp:event:모임ID:responses` 키를 지우면 됩니다.

## 배포 (Vercel)

1. Vercel에서 **Add New → Project**로 이 저장소를 가져와 배포합니다. 설정은 기본값 그대로 두면 됩니다.
2. 프로젝트의 **Storage** 탭에서 **Upstash → Redis**를 만들어 이 프로젝트에 연결합니다. 무료 플랜으로 충분합니다.
3. **Deployments**에서 최신 배포를 **Redeploy** 합니다. 환경변수는 다시 배포해야 적용됩니다.

Redis를 연결하지 않으면 모임 만들기에서 "저장소가 아직 연결되지 않았어요" 안내가 뜹니다.

앱이 읽는 환경변수는 아래 둘 중 한 쌍입니다. Vercel에서 연결하면 자동으로 들어갑니다.

| 연결 방식 | URL | 토큰 |
| --- | --- | --- |
| Vercel Storage 연동 | `KV_REST_API_URL` | `KV_REST_API_TOKEN` |
| Upstash 콘솔에서 직접 복사 | `UPSTASH_REDIS_REST_URL` | `UPSTASH_REDIS_REST_TOKEN` |

## 로컬 실행

```bash
npm install
npm run dev
```

환경변수가 없으면 메모리에 저장합니다. 서버를 끄면 데이터가 사라지니 화면 확인용으로만 쓰세요.

## 구조

| 경로 | 역할 |
| --- | --- |
| `app/page.tsx` | 모임 만들기 |
| `app/e/[id]/` | 일정 표시, 결과 화면 |
| `app/api/events/` | 모임 생성·조회, 응답 저장·삭제 API |
| `lib/store.ts` | 저장소 계층 (Upstash Redis, 로컬은 메모리) |
| `lib/dates.ts` | 날짜 계산 (전부 `YYYY-MM-DD` 문자열, UTC 기준) |

## 알아 둘 점

- 로그인이 없어서 링크를 아는 사람은 누구나 응답을 새로 쓸 수 있습니다. 민감한 내용은 적지 마세요.
- 응답 수정 권한은 브라우저에 저장됩니다. 카카오톡 안에서 응답한 뒤 다른 브라우저로 열면 고칠 수 없으니, 그럴 때는 주최자가 응답을 지워 주면 됩니다.
- 한 모임에 최대 60명, 후보 기간은 최대 92일입니다.

## 지하철역 데이터

`lib/stations.json`의 수도권 전철역 이름·좌표·역 사이 연결은 OpenStreetMap 데이터를 가공한 것입니다.
© OpenStreetMap contributors, [ODbL 1.0](https://opendatacommons.org/licenses/odbl/1-0/) (npm `korea-mcp` 0.1.0의 `data/subway.json`에서 변환).
이 파일을 고쳐서 다시 배포할 때도 ODbL을 따라야 합니다.

모이기 좋은 역은 정거장 수만으로 고릅니다. 환승 시간과 급행은 반영하지 않습니다.
